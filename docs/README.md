# Mockups

Interactive HTML mockups of minilogue xd controller. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [MLXD](mockups/MLXD.dc.html)
- [MLXD_Edit](mockups/MLXD_Edit.dc.html)
- [MLXD_Seq](mockups/MLXD_Seq.dc.html)
- [MLXD_Lib](mockups/MLXD_Lib.dc.html)
- [MLXD_Global](mockups/MLXD_Global.dc.html)
